Every account is verified with a **one-time code (OTP)** sent to your email address. Verification proves the address is yours and is required before you can check out or use the dashboard.

## Verify your email

1. After registering — or whenever you sign in to an unverified account — you see the **Verify your email** page.
2. Open the email titled *Your DeveloperJet verification code*.
3. Enter the **6-digit code** in **Verification code** and press **Verify email**.
4. You are taken to your dashboard.

## Code rules

| Rule | Current setting |
| --- | --- |
| Code length | 6 digits |
| Code lifetime | 10 minutes |
| Wrong attempts per code | 5, then request a new code |
| Wait before resending | 60 seconds |
| Codes per hour | 5 |

These limits protect your account against guessing and may be adjusted by DeveloperJet.

> **Warning:** Never share your code with anyone. DeveloperJet staff will never ask for it by phone, chat, ticket or email.

## Resending a code

Press **Didn’t get it? Resend code** on the verification page. A new code replaces the previous one — only the latest code works. If the button is unavailable, wait for the cooldown to finish.

## Troubleshooting

- **The email is not in my inbox.** Check spam, junk, promotions and any filtering rules. Search for "DeveloperJet".
- **"Code expired".** Request a new code; codes last 10 minutes.
- **"Too many attempts".** The code is locked. Request a new one.
- **I mistyped my email when registering.** Press **Use a different account** on the verification page and register again with the correct address. The unverified account cannot place orders.
- **Company mail servers.** Some corporate filters delay automated email. Ask your IT team to allow mail from the DeveloperJet domain.
