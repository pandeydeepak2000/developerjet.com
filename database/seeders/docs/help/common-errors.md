## Account and sign-in

| Problem | Fix |
| --- | --- |
| No verification email | Check spam, wait 60 seconds, use **Didn’t get it? Resend code**. [Email verification](/docs/email-verification) |
| "Code expired" / "Too many attempts" | Request a new code; only the latest code works. |
| "These credentials do not match our records." | Check the email and Caps Lock, or use **Forgot password?**. [Login and password reset](/docs/login-and-password-reset) |
| "Too many sign-in attempts" | Wait the number of seconds shown, then try again. |
| Reset link invalid | It expired (60 minutes) or was used. Request a new one. |

## Cart, checkout and payments

| Problem | Fix |
| --- | --- |
| No **Add to cart** button | The plan is not yet available online. Use *Contact Sales*. [Plan selection](/docs/plan-selection) |
| "Order unavailable" at checkout | A plan's price is pending approval or not purchasable. Remove it or talk to Sales. |
| "No online payment method is enabled yet." | Place the order and pay later, or pay with wallet funds. |
| Money debited, order still *Pending payment* | Wait 15–30 minutes for automatic reconciliation, then open a **Billing** ticket with the payment reference. Do not pay twice. [Payment methods](/docs/payment-methods) |
| Cannot cancel an order | Paid orders cannot be cancelled from the dashboard — request a refund in a Billing ticket. |

## Services and access

| Problem | Fix |
| --- | --- |
| Order stuck at *Awaiting VPS assignment* | This step is manual. If it is taking longer than expected, open a ticket. [How orders are delivered](/docs/how-orders-are-delivered) |
| Service shows *Configuration incomplete* | Add your AI provider key on the service page. [API provider configuration](/docs/api-provider-configuration) |
| "Permission denied (publickey)" | Your public key is not on the server or SSH uses another key. [SSH and security](/docs/ssh-and-security) |
| Connection timed out | Check the IP and that the service is *Active*; try another network. |
| A control shows *Unavailable* | It has not been verified for your server yet. Open a ticket for help. |

## Domains

| Problem | Fix |
| --- | --- |
| "We could not find the TXT record yet." | Check the record name and value and wait for DNS propagation. [Custom domain setup](/docs/custom-domain-setup) |
| Want to buy or transfer a domain | DeveloperJet does not sell or transfer domains. Use any registrar, then connect the domain. |
| Certificate warning | HTTPS for a custom domain is configured after verification. Use the default address until confirmed. |

## Billing and renewals

| Problem | Fix |
| --- | --- |
| No renewal reminder | Check spam and your account email. The renewal date is on the service page. [Billing and renewals](/docs/billing-and-renewals) |
| Wallet top-up still pending | Verification is manual; include a payment reference. [Invoices and wallet](/docs/invoices-and-wallet) |
| Invoice missing | Invoices exist only for verified payments. Check the order status. |

## Still stuck?

Open a ticket with the order or service selected and include what you tried. See [Support tickets](/docs/support-tickets).
