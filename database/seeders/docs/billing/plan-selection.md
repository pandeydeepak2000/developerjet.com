Every DeveloperJet product is offered as one or more plans. This guide explains how to choose the right one.

## 1. Choose the product

Start with what you want to run:

| You want to… | Product |
| --- | --- |
| Use an AI agent from a terminal over SSH | [Hermes CLI](/docs/hermes-cli) |
| Use an AI agent from a browser | [Hermes Workspace](/docs/hermes-workspace) |
| Build automation workflows | [n8n](/docs/n8n) |
| Run an isolated personal AI assistant | [OpenClaw](/docs/openclaw) |
| Run Claude Code on an always-on server | [Claude Code Hosting](/docs/claude-code) |
| Run your own containers with full root access | [Docker VPS](/docs/docker-vps) |
| Host a Node.js app or API on your own server | [Node.js Hosting](/docs/nodejs-hosting) |
| Use one API key for many AI models, with monthly credit | [AI All-Access](/docs/ai-all-access) |

Not sure? The **Compare** pages explain the differences in plain language, and [Self-hosted: who does what](/docs/managed-vs-unmanaged) explains who looks after the server.

## 2. Read the plan card

Products with more than three plans show them in a row you can move through with the arrows. Each plan card shows, in the same order:

1. **Name and short description.**
2. **Price**, or one of these labels:
   - **Indicative** — a guide price that is confirmed before you order.
   - **Pricing to be confirmed** — the price has not been approved yet.
   - **Quote on request** — priced individually after we understand your needs.
3. **Specifications** — CPU, RAM, storage, bandwidth and the access model. "To be confirmed" means the figure is not final yet.
4. **What is included.**
5. **Actions** — *Add to cart* when the plan can be bought online; otherwise *Get started* or *Contact Sales*.

> **Note:** DeveloperJet never shows a price or resource figure that has not been approved as final. If a plan shows "To be confirmed", ask Sales before relying on it.

## 3. Monthly or yearly billing

Where a plan offers both, use the **Monthly / Yearly** switch above the plans. The cart records which billing period you chose, and the renewal follows the same period. See [Billing and renewals](/docs/billing-and-renewals).

## 4. Add-ons

Some plans support optional add-ons. Add-ons are shown with their own price and are added to the same order line.

## Which plans can be bought online?

A plan can be added to the cart only when it is active, marked purchasable and has an approved price. Professional services and Business Automation are quoted individually; use *Get a quote* or *Contact Sales* for those.

## Troubleshooting

- **There is no Add to cart button.** The plan is not yet available for online purchase. Use *Contact Sales*.
- **The cart says "Pricing pending approval".** The checkout button stays disabled until the plan has an approved price.
